# Verve Release Notes

**Version:** 1.0.0  
**Release date:** 2026-09-06  
**Audience:** Customers, managers, administrators, and support teams

## Welcome

Welcome to Verve version 1.0.0. These release notes summarize the key product capabilities and considerations for this release.

## What's New

### New Features

- **Simplified onboarding:** New users can get started quickly and move through setup with clear guidance.
- **Installation support:** Administrators can review prerequisites, complete installation, and validate the deployment.
- **Secure sign-in:** Users can sign in to Verve using their configured credentials.
- **Project management:** Teams can create projects, update settings, add members, and review activity.
- **Administration controls:** Administrators can manage users, roles, and system configuration.
- **Troubleshooting resources:** Support teams can reference guidance for sign-in, startup, installation, and access issues.

### Enhancements

- Improved the product experience by organizing setup, usage, administration, and troubleshooting workflows.
- Added clearer paths for onboarding and day-to-day team use.
- Expanded guidance for collaboration, role assignment, and project operations.
- Strengthened administration workflows for managing users, roles, and system settings.
- Added troubleshooting coverage for common configuration and access issues.
- Updated product documentation to better support installation and project work.

## Considerations

- Administrator access is required for installation and administrative tasks.
- Internet access and the installation package are required before setup begins.
- Users must sign in before creating or managing projects.
- Administrators should review system settings because they influence Verve-wide behavior.
- If Verve does not start, restart it and contact an administrator if the issue continues.
- Before distributing the package, confirm the supported environment, network access, account provisioning, and organization-specific configuration.

## Limitations

- Verve currently supports a single primary workspace per user session, which may limit cross-project coordination for teams managing multiple concurrent initiatives.
- Bulk import and export features are not available for large project datasets, which may slow migration efforts for organizations onboarding from legacy systems.
- Advanced analytics and custom dashboard reporting are not included in this release, limiting visibility into trends beyond basic project activity.
- The product does not currently provide offline editing capabilities, so users must maintain a network connection to access and update project content.
- Role-based permissions are intentionally limited in this release, which may restrict highly customized governance models for complex organizations.
- Integration with external enterprise systems is constrained to the supported workflows documented in this release, and custom connectors require additional implementation work.
