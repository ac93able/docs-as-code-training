# Troubleshoot installation problems

Use this guide when Verve does not install successfully or the installation cannot be verified.

## Before you get started

- Confirm that you have administrator access.
- Confirm that you have internet access if your installation requires it.
- Download the Verve installation package again if the package is incomplete or damaged.

## Retry the installation

1. Close Verve and any other installation windows.
2. Open the Verve installation package.
3. Follow the installation wizard.
4. Select **Install**.
5. Select **Finish** when the installation completes.

Verve is installed when the wizard completes without an error.

## Verify the installation

1. Open Verve.
2. Enter your username.
3. Enter your password.
4. Select **Sign in**.

If Verve opens after sign-in, the installation is ready to use. If sign-in fails, see [Troubleshoot sign-in problems](sign-in.md).

## Frequently Asked Questions

### What should I do if the installation wizard stops?

Close the wizard, confirm that you have administrator access, and run the installation package again. Contact your administrator if the wizard stops again.

### How do I know whether the installation succeeded?

Open Verve and sign in. If the application opens successfully, the installation is ready to use.

## Best Practices

- Use the current Verve installation package.
- Complete the installation before opening Verve.
- Verify the installation immediately after it finishes.

For general troubleshooting, return to the [Troubleshooting guide](troubleshooting.md).
