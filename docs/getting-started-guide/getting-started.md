# Getting Started

Welcome to the getting-started guide for Verve.

Use this guide to prepare for installation, complete the initial setup, and see a simple first-use scenario. It is intended for first-time users and readers who need an introduction to Verve, not a complete explanation of every product task.

![Getting started overview](../images/getting-started-overview.svg)

## Guide contents

- [Overview](overview.md) — Learn what Verve does and how the documentation is organized.
- [Prerequisites](prerequisites.md) — Review the access, materials, and account requirements.
- [Getting Started Setup](setup.md) — Install Verve, sign in, and create your first project.
- [FAQs](faqs.md) — Find answers to common setup and first-use questions.

## Recommended path

1. Review the [prerequisites](prerequisites.md).
2. Complete the [getting started setup](setup.md).
3. Continue with the [User Guide](../user-guide/overview.md) for daily tasks.
4. If you administer Verve, review the [Administration guide](../administration-guide/administration.md).

## Completion checklist

You have completed this guide when you can:

- Open Verve and sign in with an active account.
- Create and open a project.
- Identify whether your next task belongs in the [User Guide](../user-guide/overview.md) or the [Administration guide](../administration-guide/administration.md).

## Next steps

After completing the setup, continue with the [User Guide](../user-guide/overview.md).
