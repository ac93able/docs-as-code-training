# Prerequisites

Before you begin, make sure you have the access and materials required to install and use Verve.

## Required before installation

- Administrator access to the computer where Verve will be installed.
- Internet access.
- The Verve installation package.
- A username and password for an active Verve account.

## Required before creating a project

After installation, open Verve and sign in. You need an active account before you can create or manage projects.

## Administrator considerations

Administrators should be prepared to manage users, roles, and Verve-wide settings after installation.
