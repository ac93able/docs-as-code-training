# Overview

This product documentation helps users install the application, sign in, create projects, and manage their work. Administrators can also manage users, roles, and system settings.

This getting-started guide provides the shortest path from preparation to first use. Follow the [prerequisites](prerequisites.md), complete the [setup](setup.md), and use the linked task guides when you are ready to work in the application.

## What you can do

- Install and verify the application using the [Installation guide](../installation-guide/installation.md).
- Sign in and create a project using the [User Guide](../user-guide/user-guide.md).
- Manage users, roles, and system settings using the [Administration guide](../administration-guide/administration.md).
- Resolve common sign-in and startup problems using the [Troubleshooting guide](../troubleshooting-guide/troubleshooting.md).
