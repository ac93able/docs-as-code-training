# Overview

Verve helps users install Verve, sign in, create projects, and manage their work. Administrators can also manage users, roles, and Verve settings.

This getting-started guide is for first-time users, users who are new to the product area, and managers who need to understand the initial experience. It provides an introduction, the basic setup path, and one example of first use. It does not replace the detailed task instructions in the [User Guide](../user-guide/user-guide.md) or the [Installation guide](../installation-guide/installation-overview.md).

The expected outcome is a working Verve installation, a successful sign-in, and a first project that you can open. Follow the [prerequisites](getting-started-prerequisites.md), complete the [setup](getting-started-setup.md), and use the linked task guides when you are ready to work in Verve.

## What you can do

- Install and verify Verve using the [Installation guide](../installation-guide/installation-overview.md) and its [verification steps](../installation-guide/verify-installation.md).
- Sign in and create a project using the [User Guide](../user-guide/user-guide.md).
- Manage users with [Manage Users](../administration-guide/manage-users.md), roles with [Manage Roles](../administration-guide/manage-roles.md), and system settings with [Manage System Settings](../administration-guide/manage-system-settings.md).
- Resolve sign-in problems using [Troubleshoot sign-in problems](../troubleshooting-guide/troubleshoot-sign-in.md) and startup problems using [Troubleshoot startup problems](../troubleshooting-guide/troubleshoot-startup.md).

## How this guide is organized

The topics follow the first-use sequence: prepare, install, verify, sign in, and create a project. Each topic has a clear outcome and links to the detailed guide for the next level of information.
