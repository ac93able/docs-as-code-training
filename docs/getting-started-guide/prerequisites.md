# Prerequisites

Before you begin, make sure you have the access and materials required to install and use the application.

## Required before installation

- Administrator access to the computer where the application will be installed.
- Internet access.
- The application installation package.
- A username and password for an active product account.

The [Installation guide](../installation-guide/installation.md#prerequisites) contains the installation-specific prerequisites and the complete installation flow.

## Required before creating a project

After installation, open the application and sign in. You need an active account before you can create or manage projects. See [Sign in](../user-guide/user-guide.md#sign-in) for the sign-in steps.

## Administrator considerations

Administrators should be prepared to manage users, roles, and application-wide settings after installation. See the [Administration guide](../administration-guide/administration.md) for those tasks.
