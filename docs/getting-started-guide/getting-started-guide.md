# Getting Started

Welcome to the getting-started guide for Verve.

Use this guide to prepare for installation, complete the initial setup, and see a simple first-use scenario. It is intended for first-time users and readers who need an introduction to Verve, not a complete explanation of every product task.

## Recommended path

1. Review the [prerequisites](getting-started-prerequisites.md).
2. Complete the [getting started setup](getting-started-setup.md).
3. Continue with the [User Guide](../user-guide/user-guide.md) for daily tasks.
4. If you administer Verve, review the [Administration guide](../administration-guide/administration-guide.md).

## Completion checklist

You have completed this guide when you can:

- Open Verve and sign in with an active account.
- Create and open a project.
- Identify whether your next task belongs in the [User Guide](../user-guide/user-guide.md) or the [Administration guide](../administration-guide/administration-guide.md).
