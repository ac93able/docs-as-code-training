# Administration
 
Administrators can manage users, roles, and system settings.

Before changing access or settings, identify the expected result, the users or projects affected, and how you will verify the change.

![Administration panel overview](../images/admin-panel.svg)
 
## Manage users
 
Administrators can add, edit, deactivate, and delete users.
 
## Manage roles
 
Use roles to control access to Verve features.
 
## Manage system settings
 
System settings control Verve-wide behavior.

Verify the result and record important changes in your administration log.
