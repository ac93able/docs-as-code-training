# Verify the Installation

Confirm that Verve starts and that your account can sign in.

## To verify Verve

1. Open Verve.
2. Enter your username.
3. Enter your password.
4. Select **Sign in**.

Verve is ready to use when the application opens successfully after sign-in.

Use this checklist to record the verification result:

```markdown
## Verification checklist

- [ ] Verve opens
- [ ] Username is accepted
- [ ] Password is accepted
- [ ] Project dashboard is available

**Verification result:** passed or failed

**Notes:**
```

If Verve does not start, follow [Troubleshoot startup problems](../troubleshooting-guide/troubleshoot-startup.md). If you cannot sign in, follow [Troubleshoot sign-in problems](../troubleshooting-guide/troubleshoot-sign-in.md).
