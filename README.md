# Verve

Welcome to the documentation for Verve. This repository contains comprehensive guides and resources for users, administrators, and support teams.

## Documentation Overview

Our documentation is organized into the following guides:

### Getting Started
[Getting Started](docs/getting-started-guide/getting-started-guide.md) - Prepare for installation, complete initial setup, and review the [FAQs](docs/getting-started-guide/getting-started-faqs.md).

### Installation
[Installation](docs/installation-guide/installation-overview.md) - Review [prerequisites](docs/installation-guide/installation-prerequisites.md), install Verve, [verify the installation](docs/installation-guide/verify-installation.md), and review [FAQs](docs/installation-guide/installation-faqs.md).

### User Guide
[User Guide](docs/user-guide/user-guide.md) - [Sign in](docs/user-guide/sign-in-to-verve.md), manage [projects](docs/user-guide/project-management.md), and collaborate with teammates.

### Administration
[Administration](docs/administration-guide/administration-guide.md) - Manage [users](docs/administration-guide/manage-users.md), [roles](docs/administration-guide/manage-roles.md), and [system settings](docs/administration-guide/manage-system-settings.md).

### Troubleshooting
[Troubleshooting](docs/troubleshooting-guide/troubleshooting-guide.md) - Resolve [sign-in](docs/troubleshooting-guide/troubleshoot-sign-in.md), [startup](docs/troubleshooting-guide/troubleshoot-startup.md), [installation](docs/troubleshooting-guide/troubleshoot-installation.md), and [project access](docs/troubleshooting-guide/troubleshoot-project-access.md) problems.

### Release Notes
[Release Notes](docs/release-notes/verve-release-notes.md) - Review the features, enhancements, known issues, and limitations documented for each release.

## How to Use This Documentation

1. **New Users**: Start with the [Getting Started](docs/getting-started-guide/getting-started-guide.md) guide to understand what you need before using Verve.
2. **Installing**: Follow the [Installation](docs/installation-guide/installation-overview.md) guide for prerequisites, setup, and verification instructions.
3. **Daily Tasks**: Refer to the [User Guide](docs/user-guide/user-guide.md) for information on how to use Verve.
4. **System Administration**: Administrators should review the [Administration](docs/administration-guide/administration-guide.md) guide.
5. **Release Updates**: Review the [Release Notes](docs/release-notes/verve-release-notes.md) for new features, enhancements, known issues, and limitations.
6. **Issues**: Check the [Troubleshooting](docs/troubleshooting-guide/troubleshooting-guide.md) guide if you encounter problems.
