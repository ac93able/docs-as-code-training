# Verve

Welcome to the documentation for Verve. This repository contains comprehensive guides and resources for users, administrators, and support teams.

## Documentation Overview

Our documentation is organized into the following guides:

### Getting Started
[Getting Started](docs/getting-started-guide/getting-started.md) - Prepare for installation, complete initial setup, and review the [FAQs](docs/getting-started-guide/faqs.md).

### Installation
[Installation](docs/installation-guide/overview.md) - Review [prerequisites](docs/installation-guide/prerequisites.md), install Verve, [verify the installation](docs/installation-guide/verification.md), and review [FAQs](docs/installation-guide/faqs.md).

### User Guide
[User Guide](docs/user-guide/overview.md) - [Sign in](docs/user-guide/sign-in.md), manage [projects](docs/user-guide/projects.md), and collaborate with teammates.

### Administration
[Administration](docs/administration-guide/administration.md) - Manage [users](docs/administration-guide/users.md), [roles](docs/administration-guide/roles.md), and [system settings](docs/administration-guide/system-settings.md).

### Troubleshooting
[Troubleshooting](docs/troubleshooting-guide/troubleshooting.md) - Resolve [sign-in](docs/troubleshooting-guide/sign-in.md), [startup](docs/troubleshooting-guide/startup.md), [installation](docs/troubleshooting-guide/installation.md), and [project access](docs/troubleshooting-guide/project-access.md) problems.

### Release Notes
[Release Notes](docs/release-notes/release-notes.md) - Review the features, enhancements, known issues, and limitations documented for each release.

## How to Use This Documentation

1. **New Users**: Start with the [Getting Started](docs/getting-started-guide/getting-started.md) guide to understand what you need before using Verve.
2. **Installing**: Follow the [Installation](docs/installation-guide/overview.md) guide for prerequisites, setup, and verification instructions.
3. **Daily Tasks**: Refer to the [User Guide](docs/user-guide/overview.md) for information on how to use Verve.
4. **System Administration**: Administrators should review the [Administration](docs/administration-guide/administration.md) guide.
5. **Release Updates**: Review the [Release Notes](docs/release-notes/release-notes.md) for new features, enhancements, known issues, and limitations.
6. **Issues**: Check the [Troubleshooting](docs/troubleshooting-guide/troubleshooting.md) guide if you encounter problems.
